# Connecting_a_Website_to_a_Database
This is a practice repo. connecting web development to databases

Hello and welcome to my practice repository!
I built this using Webstorm to practice connecting a website to a database.

There are a few dependencies if you wish to copy and run this for yourself.
You will need node.js and npm installed on your computer beforehand.
If you have any issues running the following set-up commands,
check to make sure node.js and npm are installed.

# Initial set-up
Download the repository and open with your preferred IDE. I used JetBrain's Webstorm.
Open the terminal in your IDE,
navigate to the project folder named books-db1
`cd books-db1`
You may run `pwd` to make sure you are in this directory.

Next, run `npm install`
This will use npm to install all of the dependencies and node_modules as pre-listed in package.json.
